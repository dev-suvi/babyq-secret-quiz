# BabyQ Secret Quiz

A mobile-friendly party personality quiz built with Next.js for the BabyQ party.

Guests answer seven playful questions and receive one of four secret identities:

- 🔥 Chaos Crew
- 🧠 Masterminds
- 🕵️ Secret Agents
- ✨ Wild Cards

The result is intentionally presented as a secret. On party day, the identities can be revealed as teams for group games.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this repository into Vercel and deploy with the default Next.js settings.
